# Netflix Clone

A front end clone of the Netflix landing page built using HTML and CSS.

## About the Project

This project is a recreation of the Netflix landing page developed to practise front end web development concepts such as HTML structure, CSS styling, Flexbox and page layouts.

## Technologies Used

- HTML5
- CSS3

## Features

- Netflix inspired navigation bar
- Hero section
- Email input section
- Content sections
- Frequently Asked Questions section
- Footer section
- Netflix inspired design and layout

## Project Structure

Netflix-Clone/
│
├── index.html
├── style.css
├── images/
└── README.md

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension in VS Code.
